## 1. 项目定位

V22.1 的哲学是“白盒、底层信号、冻结固定靶、球面表示”，具体落成四条不变量：

1. **不用预训练 CNN/ViT/Whisper**：视觉输入是 16×16 原始 RGB 像素（768 个数），声学输入是原始 FFT 幅度谱（512 频点），文本输入是字符整数。
2. **统一 token**：每个模态都是 `256D 球面 embedding + 384D 属性 = 640D`，经 `p7_input_proj` 投到 256D 后进入同一套 P7/ABC/P6。
3. **冻结词典**：`char_embed`（引擎）与 `bin_embed`（M1/M2）正交初始化并冻结，输入查表与输出分类共用同一本词典，避免“输入/输出两头互抢”。
4. **FP32 + 球面归一化**：生成端的全局身份 `h` 先 `F.normalize` 再乘可学习尺度；门控 `tanh` 钳位 ±2；M1/M2 全程 FP32。

生成端分三代：

- **M1**：16×16 图 → 768 位逐位 16 阶分类；验证“冻结视觉词典 + 局部均值 + 逐位身份门控”的最小闭环。
- **M2**：64×64 图 → 4×4=16 个 16×16 patch → 12288 位逐位 16 阶分类；加入 P7 跨 patch 路由、patch 内空间升级、可选的转换多样性 v2。
- **M3**：文生图，未开始。

引擎与生成端的关系：M2 只是**架构上**把 patch token 接进 P7；M2 里的 P7 是随机初始化并从头训练的，**没有加载引擎训练好的 P7 权重**。M1 完全不用 P7。

## 3. 统一 token 约定

| 模态 | embedding（256D 球面） | 属性（384D） | 进入 P7 |
|---|---|---|---|
| 文本 | `char_embed`：字符整数 → 256D，正交初始化，冻结 | `attr[0:128]` 语言属性（P3 规则），`attr[128:384]` 视觉区留空 | `char_embed + attr` = 640 → `p7_input_proj` → 256 |
| 视觉 | `16×16×3=768` 原始 RGB → `Linear(768,256)` → `F.normalize` | `attr[128:384] = P3Vis(image)`（256D），语言区留空 | 同上，640 → 256 |
| 声学 | FFT 512 频点 → `Linear(512,256)` → `F.normalize` | 384D 暂置 0（P3Aud 未落地） | 同上，640 → 256 |

关键代码：

- `train_v22_stage1.py`：`char_embed = nn.Embedding(n_chars, 256)`，`nn.init.orthogonal_`；`opt_embed = None`，优化器列表不含 `char_embed`，所以它是冻结的“固定靶”。
- `p7_input_proj = nn.Linear(640, 256, bias=False)`。
- `P3_vision/visual_token.py` 的 `image_to_token()` 是独立封装（返回 256+384=640），**引擎/M1/M2 没有 import 它**；三处各自实现了等价的 `VisualEmbed`。
- `P3_vision/p3vis.py` 的 `P3Vis.process_image()` 返回 256D，0 可学习参数；V1 色彩 48 维、V2 几何 64 维、V3 纹理 48 维、V4 深度 48 维、V5 时序 48 维（V5 为占位）。

## 4. 引擎训练入口 `train_v22_stage1.py`

### 4.1 命名与定位

文件头写的是 “V19 Turbo — 批量训练 + P3 预缓存”，日志名是 `logs/v19_*.txt`；实际训练的是 V22.1 引擎（char_embed → P7 → P3-L → ABC(A-E) → MasterGate → P6_Tied）。这是历史命名，不是旧代码。

### 4.2 数据

- 默认 `--data public` → 读取 `C:/ai/data/public/public_combined.txt`。**本机该文件不存在**；`C:/ai` 目录存在，但 `data/public/` 为空。
- 数据格式：每行 `A<TAB>B`；按 `。！？；\n` 切句；每句 3–80 字。
- 词表：`data/word_list_v2.txt`（6000 行，`词@字@字`）；`v22_train_4.tsv` 是 4 对样例，可用于极小冒烟（把 `--data` 指向它）。
- 切分：80% 训练 / 10% 测试 / 10% 考试；考试集保存为 `P1_char_word/checkpoints/V19_exam_set.pt`。
- 字符表：从数据中出现过的字符构建，另加视觉/声学标签字 `苹果太阳低中高音`，`<unk>=0`、`<pad>=-1`。

### 4.3 模型接线

```
char_embed (冻结, 256) + P3 attr (384) = 640
        │ p7_input_proj (640→256)
        ▼
P7WordRouter2048 (word_dim=256, inner_dim=256, heads=16, head_dim=16, max_len=128, num_groups=4)
        │ word_out [bs, nA, 256] + sent_vec [bs, 256]
        ▼
P3L_AttributeLinkage (attr_dim=384, num_attr_values=500, enable_vision=True)
        │ 60 维组间统计 → pad 到 128
        ▼
ABC_StageA (attr+word_out → 20 类)
ABC_StageB (content 384)
ABC_StageC (48 维语气)
ABC_StageD (11 类关系)
ABC_StageE (384 维记忆读写)
        │
        ├─ abc_prime (128→128) 渐进注入 sent / gate
        ├─ explore (TurboExplore 384→512→?)
        ├─ meta (TurboMeta_vMF 256 维 vMF 门控)
        └─ MasterGate_vMF (5 子损失 → 5 路温度)
        ▼
P6_Tied (128 个头 × Linear(256,256) → tied char_embed → 字表 logits)
```

补充：

- `P6_Tied` 在脚本内定义：`encoder(256→256→256) + pos_embed[128,256] + 128 × Linear(256,256)`；输出 `pred_vecs @ char_embed.weight.T`。
- 引擎入口的 `VisualEmbed`/`AudioEmbed` 也是脚本内定义（`proj: 768→256` / `512→256`，正交初始化），不是 `P3_vision/visual_token.py` 的类。
- `P7` 用 16 头 × 16D = 256D；`M2` 也是同一组参数，但随机初始化、从头训练。

### 4.4 损失与门控

主 loss：逐句字级 CE（`ignore_index=0`）；`p7._loss_vec = [cos_val, ce_loss]` 补零到 12 维，供下一批 P7 的 explore/meta 使用。

辅助 loss：

- `loss_A`：ABC StageA 的 20 类结构分类（按问句/感叹/否定/陈述映射到 0/12/13/6）。
- `loss_B`：StageB 内容 `ct` 与活跃 P3 属性槽的 MSE（只用非零槽位）。
- `loss_C`：StageC 前 5 维与情感槽 34–39 的 MSE。
- `loss_D`：StageD 关系审查的 11 类 CE；固定权重 0.01，不进 MasterGate 动态。
- `gate_loss`：`wg_batch.std()*10` 钳位到 [0.01,1.0]，防止词级门控塌缩。

合成：

```python
batch_loss = ce_loss
           + aux_scale * (temps[1]*loss_A + temps[2]*loss_B + temps[3]*loss_C + 0.01*loss_D)
           + temps[0]*gate_loss
```

`MasterGate_vMF` 输出 5 路温度（gate、A、B、C、CE）；当前只使用 0–3，CE 作为主 loss 不加权，第 5 路仅作为 gate 输入/观测。`aux_scale` 由 `p7.aux_val` 控制：检测到 `ac_batch` 范数暴增时冷却到 0.2，再以 1%/步恢复。

保护：

- `ce_spike`：CE 超过 EMA 的 3 倍或 >5 → `cool_down=50`、`clamp(ce_loss, max=5)`。
- NaN 梯度：逐模块扫描 `char_embed/p7/p6/p7in/p3l/abc_prime/abc_to_sent`，命中则跳过 step 并尝试从 `V21_best.pt` 恢复（见 4.6 的风险）。
- 自适应 batch：`pynvml` 监控 GPU 利用率/显存，`MEM_LIMIT_MB=8500`，在 2–32 之间调整；`MAX_BATCH_P7=32`（全词表 K/V 6166 字，超 32 会炸）。

### 4.5 视觉/声学支路

- 视觉：`_vpairs` 从 `test_images/*.bmp` 和 `test3/*.bmp` 读取，按文件名 `apple*`/`sun*` 映射到“苹果/太阳”；文本训练结束后跑 30 轮 `vision_step()`（视觉 token → P7 → P6 解码标签 + 图↔文余弦）。**本机这两个目录不存在，所以 `_vpairs=[]`，视觉支路被跳过。**
- 声学：`_sim_fft()` 生成低/中/高音三类的模拟 FFT（底噪 + 某频段能量），30 轮 `audio_step()`；声学属性 384D 暂置 0。没有外部音频数据依赖。

### 4.6 保存、加载与恢复

- 最终保存：`SAVE_DIR/V19_{MODE}.pt`，字典包含 `char_embed, p7in, p7, p6, p3l, abcA, abcB, abcC, explore, meta, master, abc_to_gate, sent_to_gate`。
- 训练中最佳：`save_best()` 写 `SAVE_DIR/V21_best.pt`，字典额外包含 `abc_prime, abc_to_sent, c2i, epoch, loss`；在 `SIGINT/SIGTERM` 时也会调用。
- 两个字典都**不完整**：`abcD, abcE, gate_base_proj, abc_to_sent（V19 最终字典）, rd_to_gate, me_to_sent, vembed, aembed` 没有保存。按现有 checkpoint 无法完整复现推理/继续训练。
- `save_best()` 第一行调用 `abcE.save_mem("C:/ai/P1_char_word/checkpoints/V22_mem.pt")`；本机 `C:/ai` 存在但 `P1_char_word/checkpoints` 不存在，若 `abcE.mem_keys` 已在训练中被写入，这里会抛 `FileNotFoundError`。

P7 的具体结构（当前配置 16 头 × 16D）：

- Q/K 投影 + RMSNorm，`scores = QKᵀ * scale * (softplus(temperature)+0.1)`；V 用 `v_heads[heads, head_dim, inner_dim]` 独立头（当前 16×16×256；类的默认配置是 32×4×128）。
- 4 个语义组（当前每组 4 头；默认 32 头时每组 8 头）；`group_bias[4, head_dim]`（当前 [4,16]）做组内软竞争；`out_proj` 把 `num_groups×head_dim`（当前 4×16=64）投回 `word_dim`（引擎/M2 为 256）。
- `explore_net(12→48→64→64)` 吃上一批 12 维 loss 向量；`meta_state(128)` 与之拼接，产生词级 gate、句级 gate、句级 mod。
- `forward_batch` 支持 padding mask、`a_lens/b_lens`；M2 的 A/B 都是 16 个 patch token。

## 6. vMF 控制层 `v22_vmf_modules.py`

文件内 16 个类，当前训练入口**只接线两个**：

| 类 | 作用 | 是否接线 |
|---|---|---|
| `TurboMeta_vMF` | 每维学习球面偏好 μ + 浓度 κ，`sigmoid(κ·cos+bias)` 替代 sigmoid 门控 | 是（`meta`） |
| `MasterGate_vMF` | 5 个子损失 → 5 路温度，每路球面偏好 | 是（`master_gate`） |

## 7. M1：`train_v22_img2img.py`

### 7.1 结构

```
16×16×3 → 768 位 × 16 阶（每通道独立量化）
退化图 bin → 冻结 bin_embed[16,256] 查表 → q_in [b,768,256]
    ctx3 = avg3 @ q_in     # 3×3 同通道均值，固定矩阵
    ctx5 = avg5 @ q_in     # 5×5
    feat = mix_in(q_in) + mix_c3(ctx3) + mix_c5(ctx5)
整图 768 + P3Vis 256 → input_proj(512→256) → encoder(256→256, GELU×2)
    h = h_scale * normalize(encoder(...))
    hp = h * tanh(clamp(gate(pos_embed), ±2))     # 逐位身份门控
    q = feat + hp + pos_embed
    logits = q @ bin_embed.T                      # [b,768,16]
```

- `bin_embed` 是 buffer（冻结），正交初始化；输入查表与输出分类共用。
- `avg3/avg5` 是 `768×768` 固定均值矩阵（同通道，仅 patch 内；M1 只有一个 16×16 patch）。
- `VisualEmbed` 是脚本内定义：`Linear(768,256)` 正交 + `F.normalize`。
- 没有 `gate_pair`（M2 才有），没有 patch 维。

### 7.2 数据/退化

- 源图：`img2img_data/*.bmp` 25 张（19 训练 / 6 考试：apple_16–20 + sun_05）。
- 通用图：`D:/ai/output/images` 顶层 300 张（**非递归 glob**；M2 才改成递归）。
- 退化：
  - T1 去噪：加高斯噪声 σ ∈ {0.1,0.2,0.3}。
  - T2 遮补：16×16 图上的 4/6/8 px 方块填 0.5。
  - T3 上色：`0.299R+0.587G+0.114B` 灰度复制三通道。
- 量化：`floor(x * n_bins)`，clamp 到 `[0,n_bins-1]`。
- 考试：每个源图每任务 1 对，退化参数固定（`SEED+1`），永不参训。

### 7.3 训练/评测

- 主 loss：逐位 CE（768 位 × 16 阶）。
- 优化器：Adam，`lr=0.012`（最佳配置），余弦退火到 0.1×。
- Stage B 最佳：`--use_generic 1 --k_labeled 16 --k_generic 4 --epochs 3000 --batch_size 1024 --gen_max 300 --lr 0.012`。

## 8. M2：`train_v22_m2.py`（当前主线）

### 8.1 结构

```
64×64 退化图 → 4×4=16 个 16×16 patch
每 patch：768 bins → 冻结 bin_embed[16,256] → q_in [b*16,768,256]
    avg3/avg5（patch 内同通道均值）
    v1: feat = mix_in(q_in)+mix_c3(ctx3)+mix_c5(ctx5)
    spatial_upgrade:
        S1: feat = mix_q(q_in)+mix_a3(ctx3)+mix_a5(ctx5)
                 + Σ_k mix_d[k](shiftM[k] @ q_in)   # 8 方向，patch 内
        S2: k_proj = attn_k(q_in + inpatch_pos); v_proj = attn_v(q_in)
            q = attn_q(feat)；分 6 块（每块 128 位）做 softmax(QKᵀ/√256) @ V
            feat += attn_o(cat(outs))                # 单头，patch 内 768 位
P7 跨 patch：
    patch_token = VisualEmbed(patch) + attr_proj(per-patch P3Vis)
    p7.forward_batch(patch_tokens, patch_tokens, [16]*b, [16]*b)
    word_out [b,16,256] → pctx_proj → 加到该 patch 的 768 位
全局身份：
    h = h_scale * normalize(encoder(input_proj(cat(sent_vec, vis_attr))))
    gp = tanh(clamp(gate_pair(cat(patch_pos, inpatch_pos)), ±2))
    q = feat + h⊙gp + patch_pos + inpatch_pos
logits = q · bin_embed.T                             # [b,16,768,16]
```

- `spatial_upgrade` 的参数增量：`mix_q/mix_a3/mix_a5` 3×65,536 + `mix_d` 8×65,536 + `attn_q/k/v/o` 4×65,536 ≈ 983K；`shiftM` 8×768×768 是 buffer（4.7M 个数，约 18.9MB）。
- `transform_v2` 的参数增量：`nbr_lin` 16×65,536 + `router` 4,096 + `attn_q4/k4/v4/o4` 262,144 + `tgate` 256 ≈ 1.31M。
- 当前最佳 S 全量：可训 2,617,236；checkpoint 34MB 主要来自 `avg3/avg5/shiftM/bin_embed` 这些 buffer，不是 34MB 参数。

### 8.2 三条前向路径

| 开关 | 路径 | 状态 |
|---|---|---|
| 默认（`spatial_upgrade 0, transform_v2 0`） | v1：局部均值 + P7 + gate_pair | 能跑；考试约 62.44%（gate_pair 修复版） |
| `--spatial_upgrade 1` | S1 方向线状上下文 + S2 patch 内邻域注意力 | **当前最佳 65.23%** |
| `--transform_v2 1` | 16 邻域 gather + router + 4 头注意力 + copy/transform 门 | **阻塞**：缺 (0,0) 自项，loss 平 ln(8)≈2.083，seen 36% |

`transform_v2` 的缺陷（代码事实）：

- `offs` 只有 16 个邻居偏移，没有 `(0,0)`（`train_v22_m2.py:268-269`）。
- `nbr_idx` 越界时填 0（自身位置）但 `nbr_mask` 把越界位置权重置 0，所以“自身”也被屏蔽（`:282-283`）。
- `acc` 是 16 条邻居支路的加权和，`q4 = acc` 不含当前像素内容（`:368-374`）。
- `copy_l` 虽然有自内容，但 `g = sigmoid(tgate(q4))` 的门控输入 `q4` 不含自内容，学不出“何时抄”（`:392-396`）。
- 对比：S2 的 `v_proj = attn_v(q_in)` 含中心位，所以 S 路径有自内容；v2 反而把自内容丢了。

### 8.7 M2 代码级缺口（与任务覆盖有关）

以下不是训练没跑够，而是当前架构没有对应逻辑（详见配套审计）：

1. **任务/σ/mask 没有进网络**：`task_t`、`sigma_t` 在 `build_pairs` 里造了，但 `run_batch` 不接收；遮补洞填 0.5，没有 mask 通道。→ 一个共享头要同时学“抄/轻平滑/强平滑/补洞”，没有开关。
2. **当前最佳没有 copy/transform 分解**：S 路径 forward 没有 copy 路；只有 v2 有 copy 门，但 v2 缺自项、被阻塞。
3. **色彩来源缺位**：`attr_i/attr_p` 取自退化图；上色输入是灰度，P3Vis 的 HSV/Lab/饱和度/色相直方图/k-means 调色板全部退化 → 每图颜色条件在“上色”任务上正好为空。没有语义/文本/参考图/调色板条件，也没有“预测干净图色彩属性”的辅助 loss。
4. **输出是逐通道独立 16 类**：不是联合 RGB/色度，没有亮度保持结构；逐通道 argmax 可以拼出训练集里不存在的颜色组合。
5. **空间仍是 patch 封闭**：`avg3/avg5`、`shiftM`、S2 都在 patch 内；P7 只到 patch token；没有像素级跨 patch。
6. **S1 是固定线性混合**：8 方向支路由一组共享 `Linear` 混合，不是逐像素路由；v2 的 router 本来是这块的补丁，但被阻塞。
7. **S2 单头**：v2 的 4 头被阻塞。
8. **指标与任务不对齐**：全图均匀 CE；遮补不单评洞内、上色不单评色度；`整图全对` 在 12288 位下恒 0，没有信息量。
9. **白盒观测量没落盘**：S2 attention map 算了但没存；h、gate、κ 也没有写日志。

同一套 108 对考试上的实测（CPU 只读基线，2026-10-26）：

| 任务/档 | 模型 S | 纯抄输入 | 3×3 均值 | 5×5 均值 |
|---|---|---|---|---|
| 去噪 σ0.1 | 49.0% | 34.6% | **50.1%** | 48.3% |
| 去噪 σ0.2 | 48.4% | 27.9% | 27.9% | 26.0% |
| 去噪 σ0.3 | 47.5% | 26.1% | 18.5% | 15.4% |
| 遮补（全图） | 86.9% | 86.0% | 57.4% | 45.7% |
| 上色（全图） | 60.4% | **57.8%（灰度当彩色）** | 45.4% | 38.3% |

读法：

- σ0.1 时模型不如固定 3×3 均值（49.0 vs 50.1）→ 低噪声没有“少动”的逻辑；σ0.2/0.3 才真正领先。
- 遮补全图只比纯抄高 0.9；洞面积 14.7%，纯抄洞内 4.0%，所以 86.9 说明不了补洞能力（全图 86.9 无法反推洞内：洞内 10.8% 时已观测 100%，洞内 40% 时已观测 95%，都成立）。
- 上色只比“输出灰度图”高 2.6；逐通道指标不区分亮度/色度。
- 迭代日志里“5×5 均值理论上限 88%、35 分可恢复”是平坦区解析上界；同一套考试上实测 5×5 均值 σ0.1 只有 48.3，所以“35 分可恢复”不成立。

## 9. 数据与评测协议（M1/M2）

### 9.1 文件与切分

| 项 | M1 | M2 |
|---|---|---|
| 带标签源图 | `img2img_data/*.bmp` 25 张 | 同 |

| 通用训练/考试 | 270 / 30（取决于 gen_max） | 370 / 30 |
| 图像尺寸 | 16×16 | 64×64 |
| 量化 | 16 阶/通道 | 16 阶/通道（S2 试过 32） |

### 9.2 退化

- T1 去噪：`clip(rgb + N(0,σ), 0, 1)`，σ ∈ {0.1,0.2,0.3}。
- T2 遮补：方块填 0.5；M1 4/6/8 px，M2 16/24/32 px。
- T3 上色：`g = 0.299R+0.587G+0.114B`，三通道复制。

### 9.3 量化与 patch 布局

- `to_bins(x) = clip(floor(x * n_bins), 0, n_bins-1)`；解码 `(bin+0.5)/n_bins`。
- M2 的 patch-major：`[64,64,3] → reshape(4,16,4,16,3) → transpose(0,2,1,3,4) → reshape(16,768)`；`from_patch_major` 是逆变换。若直接用行主序 `reshape(16,768)` 会拿不到 4×4 patch，这是 E1 修过的 bug。

### 9.4 评测

- 考试集固定（`SEED+1`），永不参训；每源图每任务 1 对。
- 指标：逐位 16 类 pixel accuracy；按任务分组；去噪按 σ 分档；`整图全对` 是 12288 位全对，基本恒 0。
- 缺陷：遮补不单评洞内；上色不单评色度；没有 joint RGB；没有结构/感知指标。因此“遮补 86.9 / 上色 60.4”会被平凡解（抄输入 / 灰度）撑高。

## 11. 已知缺陷与风险（按影响排序）

1. **M2 v2 路径缺自项**：`transform_v2` 的 16 条支路全是邻居，无 `(0,0)`；copy 门控看不到自内容；loss 平 ln8。当前最佳不使用该路径。
2. **引擎保存字典不完整**：`abcD/abcE/abc_prime(V19 字典)/gate_base_proj/abc_to_sent(V19 字典)/rd_to_gate/me_to_sent/vembed/aembed` 未保存；按 checkpoint 无法完整复现。
3. **引擎 NaN 恢复依赖缺失文件**：无条件 `torch.load(V21_best.pt)`；冷启动 NaN → 崩溃。
4. **引擎 `save_best` 记忆库路径**：`C:/ai/P1_char_word/checkpoints/V22_mem.pt` 的父目录不存在；训练写入记忆后首次保存会抛 `FileNotFoundError`。
5. **引擎入口依赖缺失**：`C:/ai/data/public/public_combined.txt`、`test_images/`、`test3/` 均不存在；视觉支路跳过，文本数据需自备。
6. **M2 指标不能区分任务难点**：遮补被已观测像素主导；上色被亮度主导；全图均匀 CE；无洞内/色度/joint 指标。
7. **M2 缺控制输入**：task/σ/mask 未进网络；低噪声没有 copy 策略；上色的颜色条件在灰度输入下为空。
8. **M2 仍是 patch 封闭 + 固定 S1 混合 + 单头 S2**；跨 patch 像素级、内容自适应、多头都被 v2 阻塞。
9. **M2 显存 cap 6.0 未验证**：19:42 改完后没有冒烟/训练；S 全量峰值 5.44GB（分配），保留池可能更高；6.0GB 余量只有 ~0.56GB。动态防护只归还缓存，不能阻止桌面应用中途涨显存。
10. **M1 通用图 glob 非递归**；M1/M2 的 `VisualEmbed/degrade/load_rgb/imread` 是重复实现，改一处不会同步另一处。
11. **命名陷阱**：`train_v22_stage1.py` 头部写 V19；`P6_Tied` vs `P6_sent_word/model.py`；三份 `VisualEmbed`。
12. **checkpoint 体积**：M2 34MB 主要是 buffer（`shiftM` 4.7M 个数 + `avg3/avg5` 1.18M + `bin_embed`），可训参数只有 2,617,236；不要把 34MB 当参数规模。
13. **敏感信息**：仓库内未发现 token/密钥（已扫描）；密钥不要提交到 git。
14. **checkpoint 反序列化**：`torch.load` 默认走 pickle，可执行任意代码；只加载本机自产的 `.pt`，不要加载来源不明的权重（必要时用 `weights_only=True` 或 `safetensors`）。

## 14. 术语表

| 术语 | 含义 |
|---|---|
| bin / n_bins | 每通道颜色量化阶数；16 阶=4096 色，32 阶=32768 色 |
| patch | 64×64 图切成 4×4 个 16×16 块；每块 768 位（16×16×3） |
| 位 / position | 一个“像素×通道”的分类位置；M2 共 12288 位 |
| seen | 训练集最后一轮的平均 pixel accuracy（不是独立评测） |
| exam | 固定退化参数的 6 张带标签 + 30 张通用图，每图 3 任务 |
| S1 | 8 方向移位线均值，patch 内 |
| S2 | patch 内 768 位邻域注意力，单头 |
| gate_pair | 身份门控吃 `(patch_pos, inpatch_pos)` 拼接交互，修复 M2 早期缺陷 |
| h | 全局身份向量：P7 sent_vec + P3Vis → encoder → 球面 × h_scale |
| P7 | 跨句/跨 patch 路由；当前引擎 16 头×16D，M2 随机初始化从头训练 |
| vMF | von Mises-Fisher 球面门控；`sigmoid(κ·cos(μ,x)+b)` |
| 冻结固定靶 | `char_embed`/`bin_embed` 正交初始化后不更新，输入查表与输出分类共用 |
| 整图全对 | 12288 位全对的图像比例；在当前精度下恒 0，不是有效指标 |
